# 車載観測端末プロジェクト (Car Observer System)

## 概要 

車内に常設するオフライン情報表示端末。

GPS・環境センサ・時刻・地図メッシュなどの情報を元に、
事前ロードしたJSONデータから状況に応じた情報を表示する。

- 車載用途
- スタンドアロン動作
- 長期ログ収集
- BLE経由でスマホ連携
- 将来的な拡張を前提とした設計

---

## 目的

- 車内でリアルタイム情報を表示
- 走行環境の記録・分析
- 地理情報に応じた表示
- 探検・フィールド用途にも使用可能な装置
- 長期運用可能な安定した組み込みシステム

---

## システム構成

### メイン制御
- Raspberry Pi Pico  
  - センサ処理
  - ログ記録
  - 表示制御
  - GPS処理

### 通信制御
- ESP32
  - BLE通信
  - スマホ連携
  - 将来的にWiFi対応予定
