# 車載観測端末プロジェクト (Car Observer System)

## 概要

車内に常設するオフライン情報表示端末。

GPS・環境センサ・時刻・地図メッシュなどの情報を元に、
事前ロードしたJSONデータから状況に応じた情報を表示する。

- 車載用途
- スタンドアロン動作
- 長期ログ収集
- JSONベース制御
- 無線通信対応（BLE / WiFi）
- 探検・フィールド用途対応

---

## 目的

- 車内でリアルタイム情報を表示
- 走行環境の記録・分析
- 地理情報に応じた表示
- オフライン動作する観測装置
- 長期運用可能な安定した組み込みシステム

---

## システム構成

### メイン制御（単一CPU構成）

- Raspberry Pi Pico W（将来的に Pico 2 W）
  - センサ制御
  - GPS処理
  - JSONデータ処理
  - SDカードログ
  - 表示制御
  - 無線通信（BLE / WiFi）
  - スマホ連携

単一マイコンで全機能を処理するシンプル構成。
