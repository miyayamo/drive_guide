# data/

装置が読み込むデータファイルを格納する。

## 内容

- 地図メッシュ情報
- 地域データ
- 表示ルール
- 辞書データ

## ディレクトリ構成

- mesh/        地図メッシュデータ
- rules/       表示条件・イベント条件
- dictionary/  文字列・ID対応表

## 重要

このディレクトリの内容は：

- SDカードにコピーされる
- firmwareから直接読み込まれる

## 設計ルール

- 文字列ではなくID中心設計
- 軽量JSON
- バージョン管理必須

## 生成方法

データは `tools/` 内のスクリプトで生成する。
手動編集しないこと。
